# GridEye 👁️
## Dual-Stage AI for Electricity Theft & Fault Detection

**FYP Future Innovation Expo'26 | IISAT University, Gujranwala**

### About
GridEye is a real-time smart grid monitoring system that uses 
AI to automatically distinguish electricity theft from technical 
faults, reducing false accusations and recovering lost revenue 
for utility providers.

### Key Features
- Dual-Stage AI: Z-Score Anomaly Detection + XGBoost Classification
- 86.18% Testing Accuracy | 1.89% Train/Test Gap
- Real-time Firebase Dashboard (Admin + Consumer)
- Live Geospatial Map across 12 Pakistani cities
- Instant Theft/Fault Alerts with ML Confidence Score

### Tech Stack
Python | XGBoost | Firebase Firestore | Flutter (Dart) | 
Scikit-learn | Google Maps Flutter
